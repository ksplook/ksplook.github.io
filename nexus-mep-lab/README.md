# NEXUS MEP LAB · 手机 / 电脑全功能网页版

公开访问地址：**https://ksplook.github.io/nexus-mep-lab/**

从私有代码仓库 `ksplook/NEXUS-MEP-LAB` 的 4.0.6 稳定发行文件同步。

## 入口
- `index.html` — v4.0.6 完整机电工程工作台；冷量、风量、液冷、供配电、BIM 工程量、BOM、询价价格库、成本比选、模块化 POD、项目管理及计算书等。
- `room-cfd/index.html?view=roomcfd` — 机房 CFD 前处理及模块化布局工作台；支持从主应用中打开和返回。**不是 CFD 数值求解器**。
- `manifest.webmanifest`、`sw.js`、`icon.svg` — PWA 主屏幕安装、离线缓存和图标。
- `docs/` — CFD 说明、设备资料、模块化和工作流程参考。

两个工作台在同一站点和 PWA 范围内运行，使用相同浏览器 origin 下的本地存储；**功能同步不等于跨设备数据云同步**。

## 在 iPhone 使用
1. 在 Safari 打开上方 HTTPS 地址，等待网页加载及离线缓存完成。新版 Service Worker 会尝试在安装时一并缓存机房 CFD；如网络中断导致这一步未成功，请联网再打开一次 CFD 页面。
2. 点击“分享” → “添加到主屏幕”。
3. 打开桌面图标，点击主工作台中的“机房 CFD / 模块化 POD 布局”进入 CFD 工作台，也可以从 CFD 页面返回。
4. 开启飞行模式，分别测试主工作台和 CFD 工作台，确认两个页面可以独立离线打开；首次缓存更新后可能需要关闭并重新打开 App。

若显示旧版，可在联网时用 Safari 重新打开地址，等待 Service Worker 更新，再彻底关闭主屏幕 App 重开。当前修复了 CFD 导航时覆盖主页面缓存的问题，并为两页分别保存离线快照。
