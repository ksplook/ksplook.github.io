# 模块化 POD 升级说明与验收记录

更新日期：2026-10-16。入口为左侧「架构与 POD 模板」。原机房、商务 POD、阿里相关历史方案及 v19 文件保留。

## 使用路径

1. 选择传统机房、集装箱、Skid 或阿里 5.0 参考分类。创建独立 IT 模块，或「1 冷却配电 + 2 IT」示例。
2. 在「建机房」分别调整模块 A/B 的 IT 功率、GPU 液冷比例、风墙、CDU、UPS 和冷源参数。高级参数默认折叠。
3. 在「看效果」选择模块与设备，修改尺寸、局部坐标、旋转和镜像；电脑可拖拽设备，手机可直接输入坐标。复制模块会复制设备并重新生成唯一 ID。
4. 在「配套设备」核对每个模块的风量、运行/备用数量、CDU、UPS、PDU、液体流量、管径和泵初算。
5. 在「看预算」输入分类单价与来源，查看按 POD/模块分组的小计与缺价。导出方案页提供基础计算书、完整 Word、布局 SVG、CFD 中性 JSON、BOM CSV 和项目备份。

原机房页的「为当前机房增加风墙与设备坐标编辑」会复制原机柜和负荷到新模型，新增配套设备位置仍须调整。切回原机房会恢复启用模块化模型前保存的机电参数。两种模型不是同时叠加的两个项目。

## 本次实现

| 验收项 | 实现与边界 |
|---|---|
| 风墙、风量与显冷 | 独立运行/备用设备，额定风量、额定显冷量、尺寸、风机功率、静压、温差和性能折减可编辑；按风量与显冷量取较大的最少运行台数，并输出设计、运行、单台分配和单机故障后显冷能力 |
| 冗余 | N+1、N+2、2N 和自定义；同时检查风量与冷量，CDU/UPS 单台故障，N+2 两台故障和2N备用组能力；不证明路径独立性 |
| 撬块布局 | 狭长参数模板，模块复制/镜像/90°旋转、逐设备拖拽与坐标编辑，设备/模块重叠及越界提示 |
| 空间对象 | GPU、NET、风墙/CRAC、CDU、PDU、RPP、UPS、水泵、障碍物；冷/热通道与检修空间参考；冷却/配电连接示意 |
| 2.4MW POD | 一个服务模块、两个1200kW IT模块；A/B 可不均分；复制/增删设备后按设备总和重新计算 |
| 冷却与配电 | IT风冷、GPU液冷、辅助空气散热分开计算；CDU流量、UPS/PDU容量、冷源名义容量校核 |
| BOM/成本 | 使用同一设备模型，项目/POD/模块/设备层级，缺价不作零元完整报价；单MW金额明确为已计价部分 |
| 计算书 | 基础 HTML 可打印 PDF，完整 Word 增加 POD 章节；项目备份、冻结快照保留模块化数据 |
| 离线 | 页面为单文件内联 JS/CSS，无数据库和计算 API；官方资料链接仅供主动查阅 |
| 旧项目 | 新字段有默认迁移，旧计算兼容；退出模块模式恢复原机电参数，历史商务数据不重写 |

## 计算验证

- 2400kW、GPU液冷90%、ρ=1.2kg/m³、cp=1.005kJ/(kg·K)、ΔT=10K：液冷2160kW、IT风冷240kW、理论风量71,641.791m³/h。
- A/B=1000/1400kW 与1200/1200kW总负荷相同；新增NET只增加风冷热量。
- 辅助散热与设计余量单独进入设计风量；机电计算增加相同的空气侧辅助负荷，液冷负荷不重复增加。
- 风墙空气侧显冷按 `Q显 = ρ × cp × V ÷ 3600 × ΔT` 计算。示例每个 IT 模块设计显冷 120kW、两台运行风墙各分配 60kW，单台可用显冷 80kW，利用率 75%；单机故障后可用显冷 160kW。
- 设备复制后总负荷、BOM数量和容量告警同步更新；镜像/旋转坐标可逆。
- 价格未知、原项目恢复、失败导入回滚、快照留存、Word生成均有回归测试。
- 浏览器实测模板创建、非均分功率、镜像/复制/旋转、拖拽写回坐标、单价与分层金额联动、重载保存及切回原方案。
- 390×844 手机视口检查：布局单列，模块操作按钮可见，设备坐标输入可用，无页面横向溢出（宽表单独横向滚动）。

测试命令：`npm test`。构建命令：`npm run build`。计算内核在 `src/modular-core.js`，界面在 `src/modular-ui.js`。

## 工程假设及待确认项

- 收到的是设计说明/参数截图，未收到带尺寸的平面CAD。16×4.8m撬块、机柜、风墙等均为可编辑示例尺寸，不是对CAD的测量复刻。
- 截图冷通道25±2℃、热通道37±2℃、RH30–54%记录为室内目标。风墙送风25℃、ΔT10K来自2.4MW示例；回风由35℃推算，不把室内目标当成设备边界。
- 截图最高干球36.6℃、最高湿球31.4℃是独立极值，不能自动配对。湿球27℃目前是明确标注的占位，需同时工况气象依据。
- PG25密度1030kg/m³、比热3.9kJ/(kg·K)，一次侧默认清水1000/4.186；均需按厂家介质和温度核实。管径/泵计算采用输入的速度、达西系数、长度、局部阻力和设备压降，无厂家泵曲线。
- 风机输入功率不会自动全部重复加入热负荷；设备“额外散热”须填写进入边界的损耗。备用设备该值同样代表实际假定散热。
- 配电按IT功率校核，平均回路负荷不能替代逐回路保护配合。2N不代表路径独立性、切换成功或正式冗余认证。
- 冷源是名义容量和组合初核，非厂家工况性能证明；仅冷却塔方案始终提示温度可行性待验证。
- 壳体/集成价格与设备价格分开，避免重复计价；清单未覆盖全部工程、税费及安装范围，不能直接作为正式报价。
- 机柜风机曲线、真实送回风开口、地板/通道泄漏、详细网格与CFD求解尚未实现。JSON包含世界坐标和概念边界，不是6SigmaRoom专用工程。
- DXF底图导入和6SigmaRoom适配器仅预留接口标记。阿里5.0分类未获官方标准产品图纸确认。
