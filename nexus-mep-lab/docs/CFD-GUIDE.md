# 从输入参数到 CFD 初始模型

本版本提供机房建模与预处理；效果图表示机柜布局、空气侧热源强度和设定流向，不是 CFD 温度/速度求解云图。

## 操作步骤大纲

1. **选择设备。** 首页进入“建机房”（简明五步流程见 WORKFLOW.md）。选择 GB300、H800、Vera Rubin NVL72 或自定义，打开官方资料核对功耗口径。
2. **填写 GPU 与 NET 功率。** 可选整柜功率，或单台服务器整机功率 × 每柜服务器数。填写 NET 整柜功率、计算负载率、GPU 液冷热捕获比例，并记录型号、资料页码和来源。
3. **排列机柜。** 设置总列数、每列 GPU 柜数和 NET 柜数、机柜宽深高。首版每列配置相同，NET 柜排在列尾；所有机柜采用统一尺寸。
4. **设置通道。** 设置冷热通道净宽、列首尾净距、外侧净距及封闭类型。相邻首两列面对面形成冷通道，后续冷热通道交替。自动生成概念顶板和端门；厚度暂取 0.05 m，漏风缝隙与真实尺寸仍需复核。
5. **建立建筑空间。** 输入机房长宽与结构层高。高架地板高度自结构楼板计；吊顶净高自完成地板计。程序检查机柜包络和顶部净空，不会自动把放不下的机柜缩小。
6. **设置冷却边界。** 选择地板或侧送风、吊顶或侧回风，填写总送风量、送风温度、初始温度及逐柜风量。逐柜风量填 0 表示未知，导出为 null，而非真实零风量。
7. **检查效果图。** 切换轴测/平面。图中柜体颜色表示空气侧热源，紫色标识 NET。检查冷热通道、机柜朝向、总功率与空气/液冷热量分配。
8. **导出。** 下载 CFD JSON、逐柜 CSV 和 SVG 效果图。通过原有“离线项目管理”导出完整项目包备份；CFD JSON 是交付给求解器前处理的文件，不是完整 NEXUS 工程备份。
9. **完成求解器前处理。** 在选定 CFD 软件中创建几何和风口，映射机柜热源、风扇曲线和阻力，设置网格、壁面、湍流与浮力模型，检查收敛和网格无关性后输出真实温度云图。

## 功率与热量

- GPU 运行功率 = 整柜设计功率 × 负载率，或整机功率 × 台数 × 负载率。
- GPU 液冷热量 = GPU 运行功率 × 液冷热捕获比例。
- 空气热量 = GPU 剩余热量 + NET 运行功率；NET 在本版按全风冷处理。
- 页面温升 = 空气热量 / (1.2 kg/m³ × 1005 J/(kg·K) × 总风量 m³/s)。它是总量能量平衡，不表示局部进风温度、回流或热点。
- 功率因数、PUE 和冗余电源容量不直接作为机柜发热倍率。本模块与原 MEP 初算参数分开保存，不自动覆盖原项目负荷。

## 导出结构

| 字段 | 内容 |
| --- | --- |
| `room` | 长宽层高、占用空间、高架地板和吊顶空腔 |
| `layout` | 列数、每列 GPU/NET 数量、通道宽度、封闭方式 |
| `cabinets` | 每柜 ID、包围盒最小点坐标、尺寸、进风面、流向、功率、风冷/液冷热量、风量 |
| `boundary_conditions` | 初始温度、送风温度和总风量、回风参考压力、待定义风口与壁面 |
| `equipment_evidence` | 选择的产品、官方来源、参考数值适用口径 |
| `unresolved` | 求解前需要补齐的项目清单 |

坐标原点为机房左前角结构楼板面。X 沿列内排列方向、Y 跨列、Z 向上；所有尺寸使用 m，热源使用 W，导出风量使用 m³/s。

## 首版范围与下一阶段

已支持规则阵列、GPU/NET 分区、热源示意、参数验证和标准化初始参数交付。暂不支持各列不同设备、逐柜混搭尺寸、真实风口/地板砖分布、通道实体、CFD 网格或求解。后续可按选定软件适配 Fluent / OpenFOAM / 其他机房 CFD 前处理格式；不能直接把当前 JSON 当作这些软件的可运行工程。
