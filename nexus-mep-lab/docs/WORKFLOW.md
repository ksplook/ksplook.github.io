# 五步使用流程

1. **建机房**：填写设备功率、列数、每列柜数和散热方式。点击“启用自动联动”，把本页作为机电负荷来源。高级设置默认折叠；已有项目参数保留。
2. **看效果**：检查机柜方向、房间包络、地板/吊顶标高和通道封闭概念几何。空间不足时回到建机房修改尺寸，或使用“按机柜布局计算房间长宽”。
3. **配套设备**：查看空气制冷、CDU、供电与冷源需求，进入各系统调整设备容量及运行/备用数量。
4. **看预算**：先看已计价部分与资料缺口，需要时进入明细编辑数量、单价和报价依据。数量按已配置设备计算，不会把需求自动当作已选定设备。
5. **导出方案**：选择 Word/PDF 计算书、CFD 参数、布局 SVG 或完整项目备份。

## 联动口径

- IT 功率 = GPU 柜和 NET 柜的功率总和 × 运行负载率。
- 全局液冷比例 = GPU 液冷热量 / 全机房 IT 功率；NET 按全风冷计入。
- 原机电模型的负荷附加系数、设计裕量、PUE、设备台数与厂家参数保留。
- 启用后，IT 功率、机柜数量、全局液冷比例由机房模型维护；解除联动后可单独修改全局模型。
- CFD 实际送风量和机电设计风量是不同口径。高级设置可主动采用设计风量，不会静默覆盖实际边界。
- 项目保存/恢复会保留联动状态；旧项目默认不改变既有计算，需主动启用。
- POD 商务方案、历史汇报方案、冻结快照和手工预算项具有独立含义，不会反写或自动改造其原始数据。
